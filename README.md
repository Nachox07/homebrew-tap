# Nachox07 Homebrew tap

```sh
brew install --cask nachox07/tap/daylit
```

[Daylit](https://github.com/Nachox07/daylit) sets external monitor brightness from the sun, or from Home Assistant (blind, room lights, solar panels).

The app is not notarized, so macOS blocks the first open: System Settings → Privacy & Security → **Open Anyway**.
